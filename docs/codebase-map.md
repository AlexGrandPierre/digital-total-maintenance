# Codebase Map

## Frontend
`src/`

React, TypeScript, UI components, hooks, and shared app types.

## Electron Shell
`electron/`

Desktop app window, IPC bridge, and Python process execution.

## Backend Engine
`modules/`

Python scanning, CSV analysis, review indexing, persistence, exports, and file actions.

## Build Assets
`build/`

Icons and app packaging assets.

## Packaged Python
`bundled-python/`

Compiled Python executables used by packaged releases.

## Packaging
`packaging/`

PyInstaller spec files and release support files.

## Scripts
`scripts/`

Repeatable local build and release helper scripts.

## Docs
`docs/`

Architecture notes, release notes, screenshots, and collaboration documentation.
