Scan Module: Digital Total Maintenance
======================================

This module scans the user's Desktop and Downloads folders and generates a 
report called scan-report.json in the same folder.

How to use:
1. Drop this ZIP into the `zips/` folder of your DTM app.
2. Wait for it to be extracted by the Electron backend.
3. Open a terminal and run:  `python3 scan.py`
4. View results in: scan-report.json

All data is read-only. No files are deleted or modified.
